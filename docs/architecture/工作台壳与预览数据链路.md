# 工作台壳与预览数据链路（as-built）

> 依据 YoAgentDocs architecture-review。覆盖 2026-09-08 全量重构，以及同日收尾审查清掉的旧架构残留。  
> 层名：Windows 桌面 `View → store → IPC → domain`；控件 `L0–L5`。

## 设计前（问题链路）

```
入口：PreviewView 自建 store，并把 windowControls 传入 TopChrome
  → TopChrome 混用 yo-titlebar__btn（46px 三键样式）做侧栏/设置
  → WindowCaptionButtons 再画一套三键，且插在带 padding 的 actions 里
  → App.tsx 设置页第三套 yo-titlebar__btn
  → YoTitleBar.tsx 第四套三键
副作用：悬停底不是贴窗口右上角的 46×40 直角块，标题栏 padding 把命中区缩进。

文档拉取：
  View → store.fetchDoc → @yohu/api/commands.safeInvoke
    → 无 Tauri 时 commands.ts 动态 import mock.ts（API 门面夹带实现 + 兼容层）
    → 再离散 setSession / loadCatalog
专栏跳转：store 硬编码 developer.huawei.com。
专栏展示名：catalogPolicy 与 webRenderer.formatCatalog 各写一套文案。
preview.css：`.yo-top-chrome {` 未闭合，后续规则全部嵌套；StatusBar 类名 `yo-preview-statusbar` 与 CSS `.yo-status-bar` 对不上。
@yohu/ui：YoTabs / YoTree / YoEmpty 内联样式双轨控件，与 CatalogTree / yo-segmented / Hero 并存。
windowShow：未使用的 API 函数带 setFocus try/catch 吞异常。
Hero onMount：navigator.clipboard.readText() 嗅探剪贴板 URL，WebView2 弹出「查看剪贴板」权限框；失败路径 try/catch 吞掉。
```

## 设计后（通路）

```
apps/shell
  registerModule(preview)
  render App

@yohu/workbench App
  createWindowSession → @yohu/api windowMinimize/Toggle/Close/IsMaximized
  路由：PreviewView | SettingsPage
  两者都只通过 YoTitleBar 画标题栏；三键只存在于 WindowCaptionButtons
  设置返回键走 YoChromeButton（与预览顶栏工具同一控件）

PreviewView
  createPreviewStore
  PreviewChrome → YoTitleBar（leading / omnibox / actions + 三键）
  body：Hero | (PrimarySidebar + CanvasDock(含 TocAside))
  StatusBar（只读指标）

拉取：
  用户回车 / 预设 / 专栏点击
  → store.fetchDoc
  → Promise.all(docFetch, docHtml, docConvert)   [@yohu/api invoke 薄转发]
  → catalogPolicy + toc 纯函数派生
  → batch 提交 UnifiedDocSession
  → 必要时 docCatalog，expandedKeys 由 catalogPolicy 计算

专栏 URL：
  resolveCatalogDocUrl(slug, currentSourceUrl) 替换当前文档路径末段，不写死域名。

专栏展示名：
  catalogDisplayName 单点；store.catalogLabel 与 webRenderer 面包屑共用。

欢迎台 URL：
  用户在输入框键入或系统粘贴（Ctrl+V），回车 → onSelectUrl → store.fetchDoc。
  不调用 clipboard.readText；复制 Markdown 仅在用户点击「复制」时 writeText。
```

## 模块职责

| 包 | 做什么 | 不做什么 |
|----|--------|----------|
| `@yohu/ui` | L0 token；YoTitleBar / WindowCaptionButtons / YoChromeButton；基础按钮/输入/卡片 | 不持有窗口 IPC、不持有文档会话、不提供第二套目录树/Tab |
| `@yohu/workbench` | 窗口会话、模块注册、设置页 | 不拉文档、不画预览画布 |
| `@yohu/module-preview` | 文档会话、专栏/画布/大纲/Hero | 不实现第二套三键、不直连 `@tauri-apps/*` |
| `@yohu/api` | 类型 + invoke / window 转发 | 不含 mock、不含 UI、不含未调用的 windowShow |

## 三键几何（WinUI）

- 标题栏高 `--yo-titlebar-h: 40px`（Tall 搜索栏）
- 三键宽 `--yo-caption-btn-w: 46px`，高度 100%，`border-radius: 0`
- 标题栏 `padding-inline-end: 0`，三键为 trailing 最后一子，贴窗口右缘
- 关闭悬停 `--yo-win-close-hover: #c42b1c`（系统关闭色，不吃普通 hover token）
- 工具按钮用 `yo-chrome-btn`（40px），禁止再用 46px 三键类

## 不引入

- 兼容层 / mock 双轨 IPC
- 第二套标题栏三键
- 模块依赖 `@yohu/workbench`
- 启动自动拉取默认文档
- 过期方案文档与旧控件双轨（YoTabs / YoTree / YoEmpty / formatCatalog）
- 启动/回到 Hero 时自动读系统剪贴板
