# 工作台壳与预览数据链路（as-built）

> 依据 YoAgentDocs architecture-review。层名：Windows 桌面 `View → store → IPC → domain`；控件 `L0–L5`。

## 设计前（问题链路）

```
身份：
  yohu-protocol::DISPLAY_NAME = YoDocPreview
  @yohu/api identity.ts 再包一层 getSystemInfo()（与 commands.systemInfo 双入口）
  架构设计-v1.md 仍写 YoWebDocPreview / com.yohu.webdocpreview
  标题栏 CSS 同时保留 yo-titlebar__title 与 yo-titlebar__home

专栏：
  领域 HUAWEI_CATALOGS 不含 *-V5，V5 URL 被当成 generic-web
  catalogDisplayName 只映射 4 个 id；webRenderer 空专栏 invent「开发指南」
  CatalogTree 每个节点同时打 yo-tree-* 与 yo-catalog-*（YoTree 双轨类名）
  专栏 id / 前缀 / 频道落地页在 domain、source、UI 各写一份
  catalogIdFromUrl 用展示名表当 allowlist
  Markdown documentPath（长专栏名 + /）与网页 documentCrumbs（频道短名 + chevron）双轨
  catalogPolicy.ts 同时持有树操作、华为身份、路径投影

控件：
  IconSidebar / IconExternal / IconCopy / IconDownload / IconRefresh 已无调用方
  as-built 仍描述已删除的主页「网页/Markdown」说明块
```

## 设计后（通路）

```
身份：
  protocol identity.rs 单源
  tauri.conf.json 由 build.rs 校验
  UI 展示名只读 @yohu/api DISPLAY_NAME（契约测试锁死）
  关于/路径仍走 system.info IPC，不再另开 getSystemInfo 别名

专栏：
  testdata/huawei-catalogs.json 单源（prefix + brand + catalogs[] + channels[]）
  domain::doc_ref include_str 该表 → parse_url / 落地 URL / 频道栏品牌
  UI huaweiCatalog.ts 导入同一 JSON（点击路径镜像，非第三份表）
  source Referer 只调 domain::huawei_doc_prefix / huawei_doc_url
  用户打开华为文档 URL，或点工作台频道栏
  → store.fetchDoc（同一入口，请求代数覆盖在途请求）
  → domain::parse_url
  → DocMeta.docRef.catalog
  → 换专栏则清空再拉 doc.catalog；同专栏只换正文
  → documentCrumbs 单源（网页 iframe 与 Markdown 文首）
  CatalogTree 只使用 yo-tree（窗格 yo-nav / yo-toc）
  文件：catalogTree.ts 树操作；huaweiCatalog.ts 身份；documentCrumbs.ts 路径投影

预览：
  主页 HomeStage / 专栏树 / 正文 <a> → store.fetchDoc（同一入口）→ doc.fetch/html/convert
  正文 href：resolveContentHref；# 本页锚点滚动，http(s) 走 fetchDoc，不让 WebView 自己开页
  壳导航：app/shell_nav 只放行 localhost / tauri.localhost / about / asset
  详情：PrimarySidebar | CanvasDock（CanvasOpBar + ChannelBar + 网页|Markdown + DocumentPath）| TocAside
  大纲点击只滚动阅读容器（offsetWithin）；网页 scroller 是 iframe 内 [data-yo-read=article]，Markdown 是 [data-yo-read=md]
  网页 toc 用正文 heading id，Markdown 用 toc-heading；点击钉住高亮直到用户自己滚
  华为标题层级 testdata/huawei-headings.json 单源：engine/huawei 与 yohu-md-huawei 同一映射
  网页阅读：isHuaweiSource → engine/huawei；isGithubSource → engine/github（GFM / 代码 / 图，按 blobKind）；否则 engine/html
  GitHub 文件树：doc.catalog 一层 Contents；githubCatalog.ts 沿 slug 祖先 / 展开空目录再拉 tree URL
  拉取：source::fetch_any 只走 route 命中的适配器，失败原样返回，不降级 generic-web
  转换：只经 yohu-library::convert 选 yohu-md-huawei / yohu-md-github / yohu-md-convert
  blobKind：protocol::BlobKind 枚举（markdown/code/image/binary/tooLarge）；HTML 源为 None
  预览图/二进制：UI engine/github 按 blobKind 画；convert 预览不编用户文案
  导出：doc.export → library::export_to_dir（不改 manifest）；GitHub 导出头去掉与正文重复的 # title
  GitHub 树 URL：githubSource.githubTreeUrlFromMeta；懒填充在 githubCatalog.ts（store 只更新会话）
  GitHub 超大文件文案读 testdata previewMaxBytes；网页 iframe 用 github-markdown.css + Prettylights 绑定 `engine/syntax` 角色（有意，不跟宿主 token 混）
  频道栏是会话控件，不进 iframe；路径不进操作栏；标题栏恒为 DISPLAY_NAME，点击 resetToHome
  主题自底而上：
    窗口   tauri.conf visible:false + 浅色底；setup 读 settings.theme + Windows AppsUseLightTheme → 底色/主题后再 show
    跟随系统  set_theme(None)，WebView prefers-color-scheme 仍跟 Windows；浅/深才钉死
    首帧   index.html 脚本写 data-theme，head 内联底色，避免 FOUC
    壳     html[data-theme] 驱动 YoUI token；settings.set 与前端 paint 再刷原生窗口底色
    频道栏 / 网页框 / Markdown 全部走 token
    网页 iframe 寿命跟文档会话，不跟阅读表面；表面走 yohu-recipe-crossfade（data-active），不卸 srcdoc
    officialSkin 颜色只挂 [data-theme=light|dark]；宿主 paintWebAppearance 涂已挂载文档
    正文块（标题/文本/图/公式/代码/提示/表）网页与 Markdown 分表面，见 [正文渲染网页与Markdown.md](正文渲染网页与Markdown.md)
  标题栏主题图标在齿轮左侧（一个图标来回切换浅色/深色）；设置页左导航 + 右分组
```

## 模块职责

| 包 | 做什么 | 不做什么 |
|----|--------|----------|
| `@yohu/ui` | L0 token；YoTitleBar / WindowCaptionButtons / YoChromeButton；基础按钮/输入/卡片；外观解析与主题卡片 | 不持有窗口 IPC、不持有文档会话、不写产品名 |
| `@yohu/workbench` | 窗口会话、主题会话、模块注册、设置页 | 不拉文档、不画预览画布 |
| `@yohu/module-preview` | 文档会话、专栏/画布/大纲 | 不实现第二套三键、不直连 `@tauri-apps/*`、不自行 settings.get |
| `@yohu/api` | 类型 + invoke / window 转发 + DISPLAY_NAME | 不含 mock、不含别名包装 |

## 工作台分区（自底而上）

```
原生窗口     隐藏创建 → 按 settings.theme 上色（system 读 Windows 应用浅/深，不钉 WebView）→ show
HTML 首帧    data-theme + 内联底色
工作台壳     YoUI token（标题栏 / 专栏 / 大纲 / 操作栏 / 状态栏 / 设置）
频道栏       专栏族切换；选中胶囊随 token 反色
画布操作栏   仅阅读开关：网页 | Markdown → 渲染/源码
文档表面     网页 iframe 与 Markdown 共用当前外观；路径只出现在这里
专栏 / 大纲  左 yo-nav 树 + 右 yo-toc 轨道
窗口标题栏   DISPLAY_NAME + 主题切换 + 设置 + 三键
设置页       左分类 + 右分组；theme 立即落盘并刷窗口底色
状态栏       只读指标
```

## 三键几何（WinUI）

- 标题栏高 `--yo-titlebar-h: 40px`（左侧应用名靠左，右侧三键贴边）
- 三键宽 `--yo-caption-btn-w: 46px`，高度 100%，`border-radius: 0`
- 关闭悬停 `--yo-win-close-hover: #c42b1c`

- 专栏表第三份实现或 catalogPolicy 兼容再导出
- yo-catalog / yo-outline / yo-guide 与现行窗格类名并行
