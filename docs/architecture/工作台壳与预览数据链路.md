# 工作台壳与预览数据链路（as-built）

> 依据 YoAgentDocs architecture-review。层名：Windows 桌面 `View → store → IPC → domain`；控件 `L0–L5`。

## 设计前（问题链路）

```
身份：
  yohu-protocol::DISPLAY_NAME = YoDocPreview
  @yohu/api identity.ts 再包一层 getSystemInfo()（与 commands.systemInfo 双入口）
  架构设计-v1.md 仍写 YoWebDocPreview / com.yohu.webdocpreview
  标题栏 CSS 同时保留 yo-titlebar__title 与 yo-titlebar__home

专栏：
  领域 HUAWEI_CATALOGS 不含 *-V5，V5 URL 被当成 generic-web
  catalogDisplayName 只映射 4 个 id；webRenderer 空专栏 invent「开发指南」
  CatalogTree 每个节点同时打 yo-tree-* 与 yo-catalog-*（YoTree 双轨类名）

控件：
  IconSidebar / IconExternal / IconCopy / IconDownload / IconRefresh 已无调用方
  as-built 仍描述已删除的主页「网页/Markdown」说明块
```

## 设计后（通路）

```
身份：
  protocol identity.rs 单源
  tauri.conf.json 由 build.rs 校验
  UI 展示名只读 @yohu/api DISPLAY_NAME（契约测试锁死）
  关于/路径仍走 system.info IPC，不再另开 getSystemInfo 别名

专栏：
  用户打开华为文档 URL，或点工作台频道栏
  → store.fetchDoc（同一入口，请求代数覆盖在途请求）
  → domain::parse_url（HUAWEI_CATALOGS + HUAWEI_CHANNELS 落地页）
  → DocMeta.docRef.catalog
  → 换专栏则清空再拉 doc.catalog；同专栏只换正文
  → catalogDisplayName / documentPath / documentCrumbs 单源
  → 路径只由文档表面消费（webRenderer 顶栏；Markdown 文首）
  CatalogTree 只使用 yo-catalog-*

预览：
  主页 HomeStage → store.fetchDoc → doc.fetch/html/convert
  详情：PrimarySidebar | CanvasDock（操作栏 + 频道栏 + 网页|Markdown）| TocAside
  频道栏是会话控件，不进 iframe；路径不进操作栏；标题栏恒为 DISPLAY_NAME，点击 resetToHome
```

## 模块职责

| 包 | 做什么 | 不做什么 |
|----|--------|----------|
| `@yohu/ui` | L0 token；YoTitleBar / WindowCaptionButtons / YoChromeButton；基础按钮/输入/卡片 | 不持有窗口 IPC、不持有文档会话、不写产品名 |
| `@yohu/workbench` | 窗口会话、模块注册、设置页 | 不拉文档、不画预览画布 |
| `@yohu/module-preview` | 文档会话、专栏/画布/大纲 | 不实现第二套三键、不直连 `@tauri-apps/*` |
| `@yohu/api` | 类型 + invoke / window 转发 + DISPLAY_NAME | 不含 mock、不含别名包装 |

## 工作台分区（自底而上）

```
文档表面     路径只出现在这里（webRenderer 面包屑/标题，或 Markdown 文首）
频道栏       专栏族切换（版本说明 / 指南 / API参考…）；Solid → fetchDoc
画布操作栏   仅阅读开关：网页 | Markdown → 渲染/源码；与专栏/大纲头同一行高
专栏 / 大纲  各自窗格头（展开折叠、收起）
窗口标题栏   DISPLAY_NAME + 设置 + 三键
状态栏       只读指标
```

## 三键几何（WinUI）

- 标题栏高 `--yo-titlebar-h: 40px`（左侧应用名靠左，右侧三键贴边）
- 三键宽 `--yo-caption-btn-w: 46px`，高度 100%，`border-radius: 0`
- 关闭悬停 `--yo-win-close-hover: #c42b1c`

## 不引入

- 兼容层 / mock 双轨 IPC / 双轨 CSS 类名
- 过期架构文档与现行实现并行
- 把网页、Markdown 渲染、源码做成三个并列模式
